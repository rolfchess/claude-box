# The words to avoid, and what to write instead.
#
# This file is the only place the list lives. check-forbidden-words.py builds its
# regexes from it and names the replacement when it blocks a write.
# render-words.py renders it into the "Words to avoid" section of
# writing-style.md, which install-defaults.sh does for you. Edit this file, run
# install-defaults.sh, and both the hook and the rules file are up to date.
#
# Format, one entry per line, fields separated by "|":
#
#   words | regex | replacement | note
#
#   words        The words as a reader sees them, separated by commas. They are
#                quoted in the rules file. The first one is the regex when the
#                regex field is empty, so it must be safe to read as one.
#   regex        Optional. A regex covering every form of the word. It is matched
#                case-insensitively, between word boundaries.
#   replacement  What to write instead. It appears in the block message and in
#                the rules file, as written here.
#   note         Optional. One more sentence for the rules file.
#
# A line starting with "## " starts a group. Its text becomes a sub-heading in
# the rules file. A group heading may name marks after the heading, in any
# order. There are two kinds.
#
# How the regex is bounded:
#
#   word          the default: the regex must match a whole word.
#   abbreviation  for a word that ends in a full stop, where a closing word
#                 boundary does not fit.
#
# Whether the group is written into the rules file:
#
#   teach         the default: the group appears in writing-style.md, so the
#                 model is told before it writes. Use it for a word a model
#                 writes unprompted, where the reminder is worth its space in
#                 the instructions.
#   hook-only     the group is left out of writing-style.md. Use it for a word
#                 a model hardly ever writes: one block with a named
#                 replacement costs less than the space would, in every session
#                 and every box.
#
# Both kinds of group are blocked. The mark decides only what the model is told
# in advance.

## A verb used of a thing that cannot do it
carry, carries | carr(?:y|ies|ying|ied) | "has", "stores", "holds" | A column stores a value; it does not carry it.
pinned, pinning | pinn(?:ed|ing) | "set", "stored", "fixed" | Write "set the provider on the order", not "pin the provider onto the order".
surfaces, surfacing | surfac(?:es|ing|ed) | "appears", "shows", "is reported" | A paid invoice appears on the feed; it does not surface on it.
holds onto | hold onto | "keeps", "stores" |
travels with | travel(?:s|ling|led)? with | "goes with", "is stored on" |
hinge, hinges | hinge(?:s)? | "depends on" |
fold, folding | fold(?:s|ed|ing)? | "put", "move", "add", "merge" | Write "add the note to the README", not "fold the note into the README".
seed, seeding | seed(?:s|ed|ing)? | "fill", "create the first", "set up" |
